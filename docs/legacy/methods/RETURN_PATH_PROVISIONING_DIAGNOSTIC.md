# 返回路径的RX占位：有因果假设的补充验证

2026-10-08。在N192扩展中，C192的合成single/dispersed均为60槽，与原B接近。
代码路径显示RX从开始接收一个字到该字经过link完成交付期间一直占位，因此先检验
发送器能力是否受到两个RX字槽限制。本补充是已有结果触发的机制诊断，不称新盲测。

## 预测与改变项

若完整字256 bit、连续打包宽度W、链路延迟L，word起点相位为k*256 mod W。
一个字占用ceil((phase+256)/W)+L个RX槽时刻。连续满宽传输的平均RX占位为：

    1 + ((L+1)*W - gcd(256,W))/256.

L=1时，128/160/192/224/256位分别需要平均1.5/2.125/2.25/2.625/2个RX字槽。
因此160/192/224满宽发送至少需要3个，256位反而2个足够。
构造单条always-ready路径的有限状态周期证书，验证RX2与RX3的可执行完整字率。

诊断不改变地址、owner、伙伴、位宽、TX深度、请求顺序或仲裁，只改rx_depth_words。
N固定192；native/request/link仍为0/1/1。所有RX都使用统一深度，是现有模型的配置粒度。
为RX3计全部制造方向增加的一个字槽，不把仅访问到的方向当成制造成本。
