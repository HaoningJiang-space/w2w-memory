# 从收益目标反求接口：N192的独立扩展

2026-10-08。此前87个独立请求实验正在执行，原协议和输入不改。本扩展由容量/生命周期
推导决定，没有查看该实验的计时输出来选择候选。使用同一份冻结owner和测试输入作配对
扩展，不另称一份新的独立测试集。

## 选择规则

固定Home256，基线归一化服务1，足宽参考的必要率上界为min(2,N/96)。取其增量的3/4
作为一个明确目标：gamma=1+3/4*(reference-1)，lambda=1/gamma。
在既有k3_23_random9_maxweight目录中逐个读取经过完整字验证的Shared独占能力、宽度
和深度。联合Home、Shared、native和占位界排除达不到目标者；选择最小Shared位宽，
再选最小深度。所有淘汰记录保留；不声称对存储/面积等多维成本全局最小。

N128给出128-bit/D1、lambda4/5；N160给出128-bit/D1、lambda2/3；N192给出
192-bit/D2、lambda4/7。N192对应现有目录的3/4 word/slot合同，宽度及深度均未增加新机制。
3/4是稳态松弛的收益目标，有限真实任务是否保留这么多增量收益由回放判断。

33个真实读回放＋14个合成实现对照。执行器和request/native/link、issue、RX合同与原研究相同。
旧结果按源文件哈希引用，原87次任务不重跑。收益保留率用同owner、同N、同任务的Home和宽k3计算。
每窗口同时报告完整时间及成本；参考无正收益时不计算保留百分比。

本扩展单独记录源码、选择证书、原始输出和验证，不把N192候选写成已有192-bit RTL物理结果。
